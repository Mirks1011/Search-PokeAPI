# Search-PokeAPI

A simple Pokémon search application built with Vanilla JavaScript using the [PokeAPI](https://pokeapi.co/).

## Features

- Search Pokémon by name
- Display Pokémon name and Pokédex ID
- Display Pokémon sprites
- Display Pokémon types with type-specific colors
- Display Pokémon abilities
- Display ability effects
- Play Pokémon cries
- Display base stats
- Calculate Base Stat Total (BST)
- Handles Pokémon with unavailable cry variants
